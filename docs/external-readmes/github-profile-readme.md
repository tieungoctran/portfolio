### 📦 Photoshop Automation Toolkit (ExtendScript / JSX)

> *Biến các thao tác lặp lại hàng nghìn lần thành một lần nhấp phím.*

1. **`batch-mockup-placer.jsx`**
   - **Mục tiêu:** Tự động mở template mockup PSD, thay thế file thiết kế vào Smart Object, căn chỉnh tỉ lệ, đổ bóng và xuất ra 30+ ảnh mockup chỉ trong 5 phút (thay vì 2-3 tiếng làm thủ công).
2. **`colorway-variant-generator.jsx`**
   - **Mục tiêu:** Nhận 1 bản vẽ master và bảng mã màu, tự động render hàng loạt phiên bản phối màu áo thun (Black, Navy, Forest Green, Heather Grey...) chuẩn in DTG.
3. **`multi-platform-spec-exporter.jsx`**
   - **Mục tiêu:** Một phím bấm xuất ra toàn bộ các biến thể file: Master Print (CMYK 300 DPI), Web Hero (RGB sRGB tối ưu <500KB), Klaviyo Banner (<200KB) và Social Carousel.
