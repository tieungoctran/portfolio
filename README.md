# TN-Project

Dự án được khởi tạo tại `D:\TN-Project`.

## 📁 Cấu trúc thư mục

```text
TN-Project/
├── docs/            # Tài liệu dự án
├── src/             # Mã nguồn chính
├── tests/           # Kiểm thử tự động (Unit / Integration tests)
├── .editorconfig    # Cấu hình chuẩn định dạng code cho trình soạn thảo
├── .env.example     # File mẫu cấu hình biến môi trường
├── .gitignore       # Danh sách file và thư mục bỏ qua khi commit Git
└── README.md        # Giới thiệu và hướng dẫn dự án
```

## 🚀 Bắt đầu

Tùy thuộc vào công nghệ bạn muốn sử dụng tiếp theo:

- **Node.js / TypeScript**: Chạy `npm init -y` để tạo `package.json`.
- **Python**: Tạo môi trường ảo với `python -m venv .venv` và kích hoạt.
- **Frontend Framework**: Sử dụng `npm create vite@latest src` hoặc các công cụ tương ứng.
