# Checklist bàn giao file

Soát trên chính file đã xuất. File nguồn đúng chưa bảo đảm file giao cuối cùng đúng.

### Nội dung và hình ảnh

* [ ] Đúng phiên bản đã duyệt.
* [ ] Soát chính tả, giá, ngày tháng và nội dung bắt buộc.
* [ ] Đúng sản phẩm, màu sắc, artwork và biến thể.
* [ ] Chữ còn đọc được ở kích thước hiển thị thực tế.
* [ ] Không còn ảnh hoặc chữ tạm.

### Thông số đầu ra

* [ ] Đúng kích thước, tỷ lệ và định dạng.
* [ ] Đúng yêu cầu về màu, độ phân giải, nền và dung lượng của nơi nhận.
* [ ] Với file in: đối chiếu vùng in, safe area và bleed theo template.
* [ ] Kiểm tra viền sáng, pixel thừa và chi tiết sát mép.
* [ ] Mở lại file xuất để kiểm tra lỗi thiếu hình hoặc sai crop.

### Quyền sử dụng

* [ ] Font, ảnh, artwork và các asset có quyền sử dụng phù hợp.
* [ ] Nội dung được phép công khai hoặc chuyển cho bên nhận.
* [ ] Không còn ghi chú hay dữ liệu nội bộ ngoài phạm vi bàn giao.

### Thư mục và phiên bản

* [ ] Phân biệt file nguồn, file sản xuất và mockup.
* [ ] Tên file thể hiện đúng SKU hoặc mã đầu việc.
* [ ] Chỉ rõ phiên bản giao cuối.
* [ ] Đã thử đường dẫn và quyền truy cập thư mục.
* [ ] Có hướng dẫn sử dụng nếu file phụ thuộc template, font hoặc script.

### Lưu ý cho POD

Với artwork placement tiêu chuẩn, có thể chuẩn bị canvas 4500 × 5400 px, 300 DPI, PNG nền trong suốt, sRGB khi nhà sản xuất chấp nhận thông số này. Vị trí in cần chừa safe area theo template. Kiểm tra kỹ nét mảnh, chữ nhỏ và độ tương phản trên áo tối.

Sublimation toàn thân và các sản phẩm khác cần template riêng; kích thước trên không thay thế thông số nhà sản xuất.
