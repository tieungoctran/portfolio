# Mẫu lưu prompt

Một prompt cần đi cùng bối cảnh sử dụng và kết quả. Khung này giúp tìm lại cách làm khi gặp đầu việc tương tự.

| Trường            | Nội dung cần lưu                      |
| ----------------- | ------------------------------------- |
| Tên               | Mô tả đúng tác vụ                     |
| Mục đích          | Đầu ra cần đạt                        |
| Công cụ / model   | Công cụ đã dùng để kiểm tra           |
| Ngày kiểm tra     | Lần gần nhất đã thử thực tế           |
| Input             | Reference hoặc thông tin cần chuẩn bị |
| Prompt            | Nguyên văn câu lệnh đã chạy           |
| Biến cần thay     | Các phần đặt trong ngoặc vuông        |
| Kết quả mẫu       | Ảnh hoặc file từ lần thử thực tế      |
| Giới hạn          | Lỗi thường gặp, chi tiết cần sửa tay  |
| Bài thử liên quan | Link tới nhật ký thử nghiệm           |

### Quy tắc đặt tên

Dùng tên tác vụ cụ thể như "Giữ bố cục khi thay bảng màu" hoặc "Phân tích hierarchy của banner". Tránh đặt tên bằng những lời hứa về chất lượng.

### Trạng thái

Prompt mới chỉ có khung thì ghi "Chưa thử". Sau khi có đầu ra thực tế, ghi rõ phạm vi dùng được. Nếu công cụ hoặc model thay đổi, thử lại trước khi cập nhật ngày kiểm tra.
