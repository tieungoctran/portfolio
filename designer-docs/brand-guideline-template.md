## 1. Logo System

### 1.1 Các biến thể logo

| Biến thể | Dùng khi nào |
|---|---|
| **Primary** (màu đầy đủ) | Nền trắng / sáng, mặc định |
| **Reversed** (trắng) | Nền tối, nền màu đậm |
| **Monochrome Black** | In 1 màu, emboss, engraving |
| **Monochrome White** | Thêu, silk screen sáng |
| **Favicon / App Icon** | Kích thước nhỏ dưới 64px |

### 1.2 Vùng bảo vệ logo (Clear Space)

```
    ←── X ──→
  ↑           ↑
  X  [LOGO]   X
  ↓           ↓
    ←── X ──→

X = chiều cao của chữ cái viết hoa trong logo
```

Không đặt bất kỳ yếu tố nào (text, icon, hình ảnh) trong vùng X này.

### 1.3 Kích thước tối thiểu

| Kênh | Kích thước tối thiểu |
|---|---|
| Print | 15mm chiều rộng |
| Digital | 80px chiều rộng |
| Favicon | 16×16px (dùng biến thể đơn giản) |

- Không dùng quá 3 màu trong một composition

- ❌ Không dùng quá 3 weight khác nhau trong một trang
- ❌ Không dùng ALL CAPS cho đoạn văn dài

## 6. Do's and Don'ts

### 6.1 Logo

| ✅ DO | ❌ DON'T |
|---|---|
| Dùng file vector (AI, SVG, EPS) | Dùng ảnh JPG/PNG chất lượng thấp |
| Giữ đúng tỷ lệ gốc | Kéo giãn không đều (stretch) |
| Dùng đúng biến thể theo nền | Đặt logo màu lên nền tương tự màu |
| Giữ đủ vùng bảo vệ | Chồng text/icon lên logo |
| | Thêm shadow, glow, hiệu ứng ngoài |
| | Xoay logo bất kỳ góc |
| | Dùng màu không có trong palette |
| | Thay đổi font trong logo |

### 6.2 Màu sắc

| ✅ DO | ❌ DON'T |
|---|---|
| Dùng đúng mã màu từ palette | Chọn màu "tương tự" bằng mắt |
| Kiểm tra contrast ratio | Dùng màu chữ / nền có contrast thấp |
| Dùng tỷ lệ 60-30-10 | Dùng đều các màu, không có trọng điểm |
| | Dùng gradient không có trong guideline |
| | Tự ý thêm màu mới |

### 6.3 Typography

| ✅ DO | ❌ DON'T |
|---|---|
| Dùng đúng font trong bộ quy định | Thay thế font tùy ý |
| Theo type scale đã định nghĩa | Dùng kích thước font bất kỳ |
| Căn chỉnh text nhất quán | Mix nhiều kiểu căn chỉnh trong một layout |
| | Dùng Italic/Bold tùy tiện không theo hệ thống |
| | Viết ALL CAPS cho đoạn dài |

## 7. Technical Specifications

### 7.1 Thông số xuất file theo mục đích

| Mục đích | Format | Color Mode | Resolution | Compression |
|---|---|---|---|---|
| **In offset** | PDF/X-1a | CMYK | 300 dpi | Không nén |
| **In kỹ thuật số** | PDF | CMYK | 150–300 dpi | PDF/X-4 |
| **POD (DTG, Sublimation)** | PNG | RGB | 150–300 dpi | Không nén |
| **Web / Social** | JPEG, WebP | RGB (sRGB) | 72–96 dpi | Tối ưu hóa |
| **Email** | JPEG, PNG | RGB | 72 dpi | < 1MB |
| **Logo master** | AI, SVG | — | Vector | — |
| **Icon set** | SVG | — | Vector | SVGO |

### 7.2 Bleed & Safe Zone cho Print

```
┌─────────────────────────────┐ ← Bleed edge (+3mm)
│  ┌───────────────────────┐  │ ← Trim edge (kích thước thật)
│  │  ┌─────────────────┐  │  │ ← Safe zone (-3mm)
│  │  │                 │  │  │
│  │  │   NỘI DUNG      │  │  │
│  │  │   CHÍNH         │  │  │
│  │  │                 │  │  │
│  │  └─────────────────┘  │  │
│  └───────────────────────┘  │
└─────────────────────────────┘

- Bleed: Kéo dài background/hình nền ra ngoài +3mm
- Trim: Đường cắt thực tế
- Safe Zone: Tất cả text và logo quan trọng nằm trong vùng này
```

### 7.3 Color Profile chuẩn

| Môi trường | Profile |
|---|---|
| In ấn (Coated) | Fogra39 / GRACoL 2006 |
| In ấn (Uncoated) | Fogra47 |
| Màn hình / Digital | sRGB IEC61966-2.1 |
| Sublimation POD | sRGB |

### 7.4 Font embedding

- **Print files**: Outline tất cả font trước khi xuất PDF
- **Web**: Dùng WOFF2 format, subset nếu có thể
- **Shared files (AI/PSD)**: Gửi kèm font hoặc dùng font có thể chia sẻ tự do
